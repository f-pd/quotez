1. Check the pods:
  kubectl get pods -l app.kubernetes.io/instance={{ .Release.Name }}

2. Try the QOTD service (RFC 865, container port 8017):
  kubectl port-forward svc/{{ .Release.Name }}-qotd-service 8017:{{ index .Values "qotd-service" "service" "tcpPort" }} &
  nc localhost 8017

{{- if index .Values "qotd-web" "enabled" }}

3. Open the website:
  kubectl port-forward svc/{{ .Release.Name }}-qotd-web 3000:3000
{{- end }}

The service runs the configuration baked into the image; API credentials
come from the Secret {{ .Release.Name }}-quotez-api (global.api.*).

More: https://github.com/f-pd/quotez
